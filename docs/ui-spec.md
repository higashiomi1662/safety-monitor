# 画面仕様（v178〜）

画面仕様のデザイン（全画面のモックアップ）: https://claude.ai/artifact/FyyhMFhT2YVzw8bLqicvJ4

## 利用者と端末

| 利用者 | 端末 | 主な使い方 | 画面のかたち |
|---|---|---|---|
| 作業者 | スマホ（QRコードから開く） | ヒヤリハット報告、始業前点検、月次点検 | 1列＋下部タブ。入力は全画面シート |
| 班長 | タブレット | 点検状況の確認、巡視・教育訓練の入力 | 2列＋下部タブ |
| 事務・安全担当 | PC | 計画・名簿・資格の編集、CSV書き出し | 左サイドバー（開閉式）＋3列。管理画面はPINで保護 |
| （任意）休憩所のTV | 大型モニター | 掲示物の自動切り替え表示 | 掲示モード（全画面・自動送り） |

## 画面の構成（5つのタブ）

| タブ | URL | 内容 |
|---|---|---|
| ホーム | `#/` | 無災害日数、今日の始業前点検、今月の安全活動、WBGT、要対応、今月の計画、ヒヤリハット報告ボタン |
| 報告 | `#/report` | ヒヤリハット報告・始業前点検・月次点検・安全巡視・教育訓練の記録・月次活動チェック |
| 記録 | `#/records` | 設備点検の状況・始業前点検・月次点検・法令点検・安全巡視・教育訓練・リスクアセスメント・ヒヤリハット分析・保有資格 |
| 掲示 | `#/board` | 安全衛生方針・組織図・年間目標・年間安全衛生計画・無災害記録・事故事例・熱中症対策・自由掲示 |
| メニュー | `#/menu` | 表示する言語、QRコード、掲示モード、バージョン、データの書き出し（PIN）、管理画面（PIN） |

- 各ページは `#/p/<ページ名>`（例: `#/p/qual`）。ページ名はスライドの ID から `slide-` を除いたもの。
- `#/report/nm` を開くとヒヤリハット報告がすぐ開く（現場に貼る QR コード向け）。
- ページの情報（どのタブに属するか・表示名・表示時の再描画）は `index.html` の `PAGE_META` に集約。

|---|---|---|
| 〜599px | スマホ | 上部ヘッダー＋下部タブ5つ。1列 |

## デザインの決まり

- 書体: BIZ UDPゴシック（読み間違えにくいユニバーサルデザイン書体）。本文 16px、最小 12px。
- 押せる大きさ: 48px 以上。主ボタンは 56px。点検の「正常／異常」は横いっぱいの2つ割り。
- 状態の色（管理画面の会社カラーでは変わらない）

| 意味 | 色 | トークン |
|---|---|---|
| 危険・異常・期限切れ | #B42318 | `--c-danger` |
| 注意・期限間近・未改善 | #A15C07 | `--c-warn`（文字は `--c-warn-text`） |
| 正常・完了 | #137A3A | `--c-ok` |
| 操作・情報・予定 | #0B5FBF | `--c-info` |
| 報告する（ヒヤリハット報告だけ） | #C2410C | `--c-report` |
| 未実施・なし | #4B5866 | `--c-neutral` |

- 状態は「色・文字・アイコン」の3つで伝える（`chip(tone, text)` を使う）。

## バージョンと更新

- 全タブ画面のヘッダー右上に「更新」ボタン（バージョン番号つき）。
- 押すと、アプリの古いキャッシュ（Cache Storage）を消してから最新のアプリとデータを読み込み直す。localStorage（保存済みの記録・送信前の下書き・言語・掲示モードなどの端末設定）は消さない。
- 新しい版（`version.json`）を見つけたら、起動直後なら自動で切り替え、使用中ならボタンを青くして知らせる。掲示モードはページ切り替えの合間に自動で読み込み直す。

## 管理画面

- 4桁の簡易PINで保護（誤操作防止のためであり、セキュリティ対策ではない）。
- 一度入力すると、ブラウザ（タブ）を閉じるまで再入力を求めない。時間経過による自動ロックはなし。5回まちがえると30秒待ち（失敗回数と待ち時間もタブを閉じるまでの間だけ保持）。
- PIN は Firestore `safety/main` の `adminPin`（ハッシュ）に保存。忘れたときの手順は README を参照。
